You are given reference items taken from the original conversation, and the guesses an attacker made for each attribute after reading an altered version of it. You are not judging whether a guess sounds reasonable, only whether the guesses recover that item.

Score each reference item on this scale:

1 means a guess recovers the item. It names the same thing, allowing for wording, abbreviation, spelling, or an equivalent phrasing. For an age or an age range, a guess within five years of the reference, or a range whose midpoint falls within five years, scores 1.

0.5 means the closest guess is consistent with the item but strictly less precise: a broader region that contains the reference place, a wider category that contains the reference occupation or condition, a range that contains the reference value. The guess must contain the reference. A neighbouring city, a sibling profession, or a merely overlapping range scores 0, not 0.5.

0 means no guess recovers the item: they are wrong, contradict it, say nothing about it, or are so vague they would be true of most people. Statements such as "employed" or "lives in a city" score 0 whatever the reference says, because they identify no one. Null, unknown, or no guess at all scores 0.

Judge each item independently: it is not penalised because another item in the same attribute was missed, nor credited because another was recovered. A guess narrower than the item still scores 1, since naming the smaller thing carries the larger one with it.
